# docker-mailserver-build

Regular image rebuilds of https://github.com/docker-mailserver/docker-mailserver

Support table:

| Major version    | Images rebuilt weekly       |
| ---------------- | --------------------------- |
| Current (16.x)   | All                         |
| Previous (15.x)  | Latest minor (15.1.x)       |

Discontinued:

| Major/minor version | Last update              |
| ------------------- | ------------------------ |
| 15.0.x              | 2026-08-29               |
| 14.x                | 2026-04-18               |
| <= 13.x             | Deleted from registry    |

Docker images can be found at https://hub.docker.com/r/aspettl/docker-mailserver
